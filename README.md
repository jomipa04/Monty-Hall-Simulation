🎯 Monty Hall Simulation in Python
A simple Python script that simulates the famous Monty Hall problem to demonstrate the counterintuitive probabilities behind the "switch or stay" game show strategy.

🧠 What is the Monty Hall Problem?
It's a probability puzzle based on a game show scenario:

1. You're shown 3 doors — behind one is a car (win), behind the others are goats (lose).

2. You pick one door.

3. The host (Monty), who knows what's behind the doors, opens one of the other two doors to reveal a goat.

4. You're then offered a choice: stick with your original door or switch to the remaining unopened door.

Statistically, switching gives you a 66.7% chance of winning, while staying only gives you 33.3%.
